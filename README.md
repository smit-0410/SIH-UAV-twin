# SIH UAV Digital Twin

A simulation and digital-twin framework being developed for **Smart India Hackathon 2026**.

The project aims to provide a virtual representation of a UAV and its propulsion system for simulation, monitoring, fault detection, and future synchronization with physical UAV telemetry.

## Project Status

**Under active development**

The repository currently contains the physical and digital-twin foundations for a **Rotax 914 engine**, including:

* Engine dynamics
* Propeller aerodynamic modelling
* Atmospheric and environmental inputs
* Sensor modelling
* Healthy-state estimation
* State synchronization
* Residual analysis
* Health-state estimation
* Configuration-driven parameters
* Automated testing and validation

The **UAV-level simulation and integration layer** is currently under development and will build on these propulsion and digital-twin foundations.

## Architecture

The project is being developed as a layered system in which the UAV simulation provides the virtual aircraft, while the digital-twin layer provides independent state estimation, comparison, and health monitoring.

## Current Components

### Engine Digital Twin

The `sih-rotax-engine-main` module contains the current engine simulation and digital-twin implementation.

It includes modelling and infrastructure for:

* Rotax 914 engine behaviour
* Engine dynamics
* Propeller aerodynamics
* Atmospheric and environmental conditions
* Sensor behaviour
* Healthy reference state estimation
* State synchronization
* Residual analysis
* Health-state estimation
* Configuration management
* Automated testing and validation

### Propeller Model

The propeller model converts engine-derived propeller RPM and operating conditions into aerodynamic quantities using non-dimensional propeller relationships.

The model calculates:

* Advance ratio
* Thrust coefficient
* Torque coefficient
* Aerodynamic thrust
* Aerodynamic torque
* Absorbed power
* Propeller efficiency

Numerical safeguards are included for low and zero RPM conditions.

### Independent Healthy Reference

A key part of the digital-twin architecture is the **independent healthy reference model**.

The expected engine state is not generated by simply copying the internal state of the physical simulation. Instead, it is estimated from the operating context and environmental conditions.

The reference model considers parameters such as:

* Pilot throttle command
* Ambient conditions
* Expected manifold absolute pressure (MAP)
* Expected RPM
* Airflow
* Fuel flow
* Engine temperatures

This separation allows the digital twin to compare an independently estimated healthy state against an observed state and identify deviations that may indicate abnormal behaviour or faults.

### State Synchronization

The synchronization layer ensures that the expected and observed states are temporally aligned before residual and diagnostic analysis is performed.

This helps prevent timing mismatches from being interpreted as physical deviations.

## Development

The project follows a phased development approach.

The current implementation focuses on establishing a physically consistent propulsion and digital-twin foundation before integrating the complete UAV simulation.

Planned development areas include:

* UAV flight-dynamics simulation
* UAV-level sensor simulation
* Environmental modelling
* Propulsion-to-flight integration
* Telemetry interfaces
* Real-time digital-twin synchronization
* Fault injection and validation
* UAV health monitoring

These components will progressively connect the existing engine digital twin with the larger UAV simulation.

## Validation

The engine digital-twin implementation includes automated unit and integration tests covering the physical and digital-twin components.

Validation focuses on:

* Numerical stability
* Physical consistency
* State synchronization
* Power-envelope consistency
* Integration behaviour
* Fault-detection behaviour

Detailed validation results and engineering audits are documented in the project documentation.
